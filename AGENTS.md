# Public Repo Agent Notes

This is the public Jekyll source repository for the Demokratia Info website.

Keep this repository public-safe:

- Do not commit operational handover notes, automation prompts, runbooks, private queues, author-contact records, editor credentials, visitor contact details, private editor notes, or original user-uploaded feedback photos.
- Keep private operational material in `democracy-paper-suggestions-private`.
- Do not manually edit generated HTML, `_site/`, or Pagefind output.
- Edit paper summaries in `_papers/`, shared templates in `_layouts/` and `_includes/`, and public metadata in `_data/`.
- Validate public source changes with `python3 scripts/validate_sources.py` before committing when paper data or queues change.

Operational automation instructions are intentionally not stored in this public repository.
